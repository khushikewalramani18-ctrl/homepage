# Spoke & Co. – Homepage

- **Library:** React Bootstrap (official Bootstrap components for React), inside a Vite + React app.
- **Install:** `npm create vite@latest` (React template), then `npm install react-bootstrap bootstrap`.
- **Run:** `npm install`, then `npm run dev`. Build with `npm run build`.
- **Components used:** `Navbar`, `Nav`, `Container`, `Row`, `Col`, `Button`, `Card`.
- **My layout components** (`src/components/`): `AppNavbar`, `Hero`, `Features`, `Footer`.
- **What it saved me from writing:** the responsive navbar. `Navbar.Toggle` and `Navbar.Collapse` give me the mobile hamburger menu, open/close state and accessibility attributes without any custom JavaScript.
